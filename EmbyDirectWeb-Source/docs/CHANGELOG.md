# 历史开发记录

以下按历史版本保留；现行功能和使用方式以根目录 README 为准。

# v0.16 播放控制与默认字幕

底部播放键旁增加后退/前进五秒，限制在影片范围内；五秒是定位目标，长关键帧间隔文件的实际落点受播放器内核影响。独立播放页的播放信息和设置放在顶部标题栏，不遮挡视频；多窗口播放放在各自标题栏。默认启用 Emby 默认可用外挂，否则第一条可用外挂；没有外挂时启用内嵌字幕。手动选择关闭后本次播放保持关闭。视频链路和转码策略不变。

# v0.15 Emby 外挂字幕入口与轨道合并

播放器底部“字幕”点击后直接打开统一字幕选择，列出 Emby 外挂、内嵌及本地字幕。服务器读取时合并当前媒体源和影片级轨道，避免音视频轨道非空时遗漏外挂；没有外挂时补查 Items 详情接口。选择字幕只下载服务器字幕文件，视频保持 302 原文件播放。播放信息新增字幕轨道诊断，不包含字幕路径、令牌或签名直链。

# v0.14 浏览器预加载与历史播放

登录后后台预加载媒体目录，完成后类型、年份、演员和排序在浏览器筛选。首次 Emby 返回较慢时，预加载完成前仍可能等待；预加载不下载视频。分类导航改为历史播放，类型筛选保留。

媒体目录和本网页播放历史存入当前浏览器 IndexedDB，按 Emby 地址和账号隔离。程序不保存媒体目录缓存，不把连接信息写入安装包。密码和登录令牌不持久化；地址和用户名仅在勾选“记住连接信息”后保存到当前浏览器。分享 Windows ZIP 不包含浏览器资料。历史播放记录本网页播放；继续观看仍读取 Emby。

筛选设置可清除此账号的浏览器缓存与历史。正常使用端口 18765；端口被占用时其他端口的浏览器存储独立。目录缓存十分钟后后台更新，最多五万条。

# Emby Direct Web 0.13（Windows 测试版）

## 使用
1. 解压便携包到任意目录，双击 EmbyDirectWeb.exe。保留同目录 runtime 文件夹。
2. 程序自动打开浏览器。填写原 Emby / 302 地址（包含协议和端口）及原账号密码。
3. 打开媒体库选择影片；影片在新标签页播放，最多同时四路。音轨、字幕、音量、进度与倍速在各播放器底部设置。
4. 右下角系统托盘图标可重新打开网页或退出程序。关闭网页不会退出本机服务。

无需安装 Python、Node、Docker，不需修改 HK 服务器，也不需填写 115 Cookie。默认仅监听 127.0.0.1:18765；端口被占用时自动选择空闲端口。

## 播放链路
Emby/原302服务负责账号、媒体库和直链。程序只接受原文件入口的 HTTP 跳转；视频由本机按 Range 从最终115地址读取，再由浏览器本地解封装和解码。最终视频地址仅允许 115.com、115cdn.com、115cdn.net 及其子域名；未知域名会停止，需根据真实链路核实后适配。

这是“家里电脑直连115 + 本机中转给浏览器”，浏览器开发者工具显示127.0.0.1媒体地址是预期行为。HK不转发视频。不会请求服务器转码、DirectStream、HLS转码清单或字幕烧录，不先下载整部影片。

## 已验证与限制
已用模拟Emby/302与真实生成的30秒视频，在Windows Chrome检查MP4 H264/AAC、MKV H264/AC3、MKV HEVC/EAC3的四路并发本机播放、视频及音频实际渲染、多音轨切换、拖动和进度回报。测试片为640×360，不能代表4K/HDR/Dolby Vision或所有DTS变体。真实115链路还需用户本机验收。

播放器内核本地固定为libmedia AVPlayerUI 1.3.1，优先WebCodecs硬件解码，不支持时本地WASM软解。复杂音轨会解码为浏览器音频输出；不承诺家庭影院位流直通。音频使用内核自带的兼容输出方式。内嵌字幕由内核处理（已检测到测试字幕轨道，字幕实际显示尚未完成验收），可手动加载本机SRT/ASS/SSA/VTT；Emby侧外挂字幕自动获取目前未实现。

页面登录密码和Emby令牌只保存在内存，浏览器只记住连接地址和用户名。刷新页面后需重新登录，退出程序后需重新登录。不要把程序改为监听公网。

## 常见问题
- 登录返回HTML或跳转：填写能直接访问Emby API的地址；尝试原服务要求的 /emby 路径。
- 提示“原文件入口未返回302”：当前程序使用 /Videos/ID/stream?static=true；你的302方案可能只处理不同路径，需要按实际插件适配。不会悄悄从HK下载视频。
- 115返回401/403：检查现有方案的UA/IP绑定。在高级设置填原客户端要求的User-Agent。程序会在401/403/410时重新获取一次链接，失败即停止。
- HTTPS证书错误：使用有效证书和正确域名，程序不关闭TLS验证。
- 无声音/卡顿：先单路播放，确认浏览器有声音输出设备；4K软解、多路播放需要按实际机器验收。

## 0.2 修正
点击分类后递归列出全部视频，隐藏中间目录；仍采用分页读取。播放前读取最多 4096 字节原文件头识别 MKV/MP4，避免 STRM 元数据误导播放器。播放错误附带格式、主机、读取失败原因，不包含账号密码或带签名直链。真实 115 的本次报错尚需试播确认。

## 0.4 修正
MPEG-TS 媒体源的 mpegts 名称转换为内核识别的 ts，已复现原错误并验证修正后的 TS 音视频播放。封面悬浮显示播放图标并缩放变暗，点击影片打开独立新标签页，沿用本机登录。分类仍递归展示全部影片。最多同时四个播放会话（包括各个标签页）。

## 0.5 性能与界面
采用 Emby 风格分类侧栏、海报墙、影片详情和全窗口播放布局。封面右下角可打开详情，影片点击仍在新标签播放。减少起播缓冲至1秒；TS初始探测时长1秒（其他格式3秒）；复用已验证文件大小以免HEAD再次读取115；媒体连接池与一分钟DNS缓存；首批数据按16KB传出；不同播放会话独立解析直链。TS无完整索引时仍可能需要多次Range探测，尚未在用户真实115链路测量提速幅度。播放页悬浮显示“播放信息”，可复制准备、缓冲、跳转和读取耗时继续诊断。CPU/GPU低占用不代表硬件未启用，数据等待也会造成低负载。

## 0.6 续播与介绍
续播改为先定位到保存位置再起播，避免先从头播放再跳转。TS有可靠Emby片长时，以文件大小/片长估算初始位置并提前2秒开始扫描，保留内核时间戳校正、关键帧扫描及二分回退；缺少片长时使用原算法。VBR文件和长关键帧间隔仍可能较慢，真实网盘尚需验收。详情明确请求Overview/People/Genres等完整字段，必要时使用Items接口补充；弹框即时显示标题与加载状态，错误在框内展示。内核文件使用版本化地址，避免浏览器缓存继续加载旧实现。

## 0.7 页面交互
海报中央播放按钮直接在新标签播放；其余位置进入独立影片详情页。详情页展示背景、海报、时长评分、媒体规格、发行日期、简介、全部演职人员、媒体源信息，并提供全部已获取元数据（去除路径及敏感鉴权字段）展开查看。外挂字幕移到播放设置对话框。该版未宣称解决真实115拖动十几秒的问题，尚需拖动后的播放诊断定位耗时。

TS定位更新：根据用户诊断（连续二分探测、每次响应头约0.7秒）采用已读取到的位置/时间戳做插值定位，异常估计回退二分查找，并缓存本次会话的定位样本。真实网盘提速幅度仍需用户验收。

## 0.8 定位样本复用
用户0.7诊断lastSeekMs=1934，剩余网盘响应头等待约0.7-0.8秒/次。TS跳转初次估算也优先复用本次打开文件已采集的位置/时间戳样本，减少重复试探；无有效样本保持原估算与二分回退。跨会话样本持久缓存及数据块缓存尚未实现。真实提速幅度需要用户试播。

## 0.9 界面调整
参照 Emby 详情页调整大海报、背景遮罩、透明侧栏、顶栏返回按钮、横排媒体规格和演员卡片；海报播放按钮继续在新标签页播放。播放内核、302 链路和跳转算法沿用 0.8。

## 历史版本记录（以下缓存机制已被 0.14 替换）

## 0.10 分类与筛选
媒体库提供影片／分类入口。上方支持真实类型多选、年份、最新上映、最近添加及评分排序；筛选设置保存 OR（任一符合）或 AND（全部符合）。详情页类型和演员可以点击查询作品，返回按钮恢复原媒体库、筛选、页码和滚动位置。AND 在完整候选结果中筛选后分页，元数据缓存 60 秒；候选超过五万部会提示缩小范围，不返回不完整结果。播放内核与 302 视频链路未调整。

## 0.11 分类兼容与 Emby 外挂字幕
分类接口失败时依次尝试 Filters2 和影片元数据全库汇总，兼容结果缓存 10 分钟。回退首次读取可能较慢，推荐先选择具体媒体库。
播放页面右上角“播放设置 → 字幕”列出 Emby 外挂、内嵌及已加载的本地字幕，可切换或关闭；选择外挂后只下载字幕文件，视频继续原 302 直连。Emby 标记的默认文本字幕会异步加载，不阻塞开始播放。支持 SRT/ASS/SSA/VTT 文本字幕；图片型外挂字幕标注暂不支持，不烧录或转码视频。外挂字幕须先被 Emby 扫描识别。

## 0.12 类型收起与分类查询兼容
类型栏默认显示前 10 个选项，点击右侧 ＋ 展开全部，− 收起。展开区限制高度并可滚动，已选择的类型不会因收起而隐藏。分类名称与原始元数据不做清理或删除。
当 Emby 按类型查询返回 HTTP 500 时，保留媒体库、年份、演员和排序限制，用影片类型元数据匹配 OR/AND 并在完整结果中分页。回退扫描缓存 60 秒，首次读取可能较慢；超过五万部提示限定媒体库，不返回不完整结果。权限错误仍正常报告。播放和字幕沿用 0.11。

## 0.13 分类共享索引与耗时诊断
回退查询改为共享整份候选元数据，不再按所选类型或 OR/AND 分别扫描；相同媒体库、年份、演员、搜索及排序条件之间切换类型复用数据，已知不兼容查询不再重复请求失败接口。首次读取仍需要等待，切换媒体库或其他查询条件可能需要建立新的索引。
索引保留最近 8 份，10 分钟后后台更新；刷新失败保留完整旧数据并隔一分钟重试。重启程序清除缓存。
/api/items 响应含 CatalogTiming（上游耗时、请求次数、缓存命中、本机耗时），并提供 Server-Timing 供浏览器 Network → Timing 查看。播放和字幕未调整。
